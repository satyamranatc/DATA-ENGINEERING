Installation

Get pyttsx3 and its dependencies up and running

pyttsx3 works offline. It talks to the native TTS engine on each OS — no API keys, no internet, no cost.

  • macOS → uses nsss (NSSpeechSynthesizer)
  • Windows → uses sapi5 (Microsoft Speech API)
  • Linux → uses espeak (needs to be installed separately)
Tip Always install inside a virtual environment. Run python -m venv .venv && source .venv/bin/activate first.
Terminal 
# Install pyttsx3
pip install pyttsx3

# macOS — no extra deps needed
# Windows — no extra deps needed
# Linux — install espeak first:
sudo apt-get install espeak
macOS Monterey/Ventura/Sonoma If you get a "No module named 'objc'" error, run: pip install pyobjc

Say Your First Words

The three key methods: init → say → runAndWait

Every pyttsx3 program follows the same three-line pattern:

  • pyttsx3.init() — create the engine (connects to the OS TTS driver)
  • engine.say(text) — queue the text to be spoken
  • engine.runAndWait() — speak the queue and block until done
hello_speak.py 
import pyttsx3

# 1. Create the TTS engine
engine = pyttsx3.init()

# 2. Queue text to speak
engine.say("Hello! I am your Python assistant.")
engine.say("pyttsx3 works completely offline.")

# 3. Speak the queue (blocks until done)
engine.runAndWait()
What happens You can call engine.say() multiple times — they are queued and spoken in order when you call runAndWait().

Change the Voice

List available voices and switch between them

Your OS ships with multiple voice profiles. pyttsx3 lets you list them and pick one by index or by ID string.

voices.py 
import pyttsx3

engine = pyttsx3.init()

# List all voices 
voices = engine.getProperty('voices')

for i, voice in enumerate(voices):
 print(f"[{i}] {voice.name} → {voice.id}")

# Set voice by index 
# index 0 → usually the first installed voice (e.g. "Alex" on Mac)
engine.setProperty('voice', voices[0].id)
engine.say("This is voice number zero.")

# Try index 1 if available
if len(voices) > 1:
 engine.setProperty('voice', voices[1].id)
 engine.say("And this is voice number one.")

engine.runAndWait()
Voice PropertyWhat it gives you
voice.idUnique identifier string — pass this to setProperty
voice.nameHuman-readable name (e.g. "Samantha", "Alex", "Daniel")
voice.languagesList of language codes (e.g. ['en_US'])
voice.gender'VoiceGenderMale' / 'VoiceGenderFemale'

Speed & Volume

Fine-tune how fast and how loud your assistant speaks

Use getProperty to read the current value and setProperty to change it.

speed_volume.py 
import pyttsx3

engine = pyttsx3.init()

# Rate (speed) 
# Default: 200 words per minute
rate = engine.getProperty('rate')
print(f"Default rate: {rate}") # → 200

engine.setProperty('rate', 150) # slower — easier to understand
engine.say("This is slower speech at 150 words per minute.")

engine.setProperty('rate', 250) # faster
engine.say("This is faster speech at 250 words per minute.")

# Volume 
# Range: 0.0 (silent) → 1.0 (max)
volume = engine.getProperty('volume')
print(f"Default volume: {volume}") # → 1.0

engine.setProperty('volume', 0.8)
engine.say("Volume is now at 80 percent.")

engine.runAndWait()
PropertyDefaultRangeUnit
'rate'20050 – 400+Words per minute
'volume'1.00.0 – 1.0Float (0 = silent)
Sweet Spot For a Jarvis-style assistant, rate=160 and volume=0.9 sounds very natural and authoritative.

Events & Callbacks

Hook into speech events to run code during or after speaking

pyttsx3 fires events as speech progresses. You can attach Python functions to these events using engine.connect().

events.py 
import pyttsx3

engine = pyttsx3.init()

# Callback: called when an utterance starts 
def on_start(name):
 print(f" Started speaking: '{name}'")

# Callback: called when a word is spoken 
def on_word(name, location, length):
 print(f" Word at position {location}, length {length}")

# Callback: called when speech finishes 
def on_end(name, completed):
 print(f" Finished: '{name}' — completed={completed}")

# Connect callbacks to events
engine.connect('started-utterance', on_start)
engine.connect('started-word', on_word)
engine.connect('finished-utterance', on_end)

engine.say("Hello from pyttsx3 events!", "greeting")
engine.runAndWait()
Event NameWhen it firesCallback signature
'started-utterance'Speech begins for a queued itemf(name)
'started-word'Each word as it is spokenf(name, location, length)
'finished-utterance'One queued item finishesf(name, completed)
'error'A speech error occurredf(name, exception)

Save Speech to a File

Export spoken audio as an .aiff or .mp3 without playing it

Instead of playing audio live, you can save it to a file using engine.save_to_file(). This is useful for pre-generating audio responses.

  • On macOS the default format is .aiff
  • On Windows the default is .wav
  • Convert with pydub if you need .mp3
save_audio.py 
import pyttsx3

engine = pyttsx3.init()

engine.setProperty('rate', 160)
engine.setProperty('volume', 1.0)

text = "Hello Boss. I am online and listening."

# Save to file — does NOT play audio
engine.save_to_file(text, "greeting.aiff")
engine.runAndWait()

print(" Saved to greeting.aiff")
Convert to MP3 Install pip install pydub and ffmpeg, then:
AudioSegment.from_file("greeting.aiff").export("greeting.mp3", format="mp3")

Mini Project — Jarvis Greeter

Put it all together into a reusable speaker class

Here's a clean, production-ready Speaker class that wraps pyttsx3 — the same pattern used in your Jarvis bot's voice.py.

jarvis_speaker.py 
import pyttsx3
import datetime


class Speaker:
 """A clean wrapper around pyttsx3 for a voice assistant."""

 def __init__(self, rate=160, volume=0.9, voice_index=0):
 self.engine = pyttsx3.init()
 self.engine.setProperty('rate', rate)
 self.engine.setProperty('volume', volume)

 # Pick a voice by index
 voices = self.engine.getProperty('voices')
 if voice_index < len(voices):
 self.engine.setProperty('voice', voices[voice_index].id)

 def speak(self, text: str):
 """Speak the given text aloud."""
 print(f" {text}")
 self.engine.say(text)
 self.engine.runAndWait()

 def greet(self):
 """Say a time-aware greeting."""
 hour = datetime.datetime.now().hour
 if hour < 12:
 greeting = "Good morning, Boss."
 elif hour < 17:
 greeting = "Good afternoon, Boss."
 else:
 greeting = "Good evening, Boss."

 self.speak(greeting + " I am online and ready.")

 def save(self, text: str, filename: str):
 """Save speech to an audio file without playing it."""
 self.engine.save_to_file(text, filename)
 self.engine.runAndWait()
 print(f" Saved → {filename}")


# Run it 
if __name__ == "__main__":
 jarvis = Speaker(rate=160, volume=0.9)
 jarvis.greet()
 jarvis.speak("pyttsx3 is now your voice engine. All systems go.")
 jarvis.save("Saved this response.", "response.aiff")
You're Done! This Speaker class handles voice selection, rate, volume, greeting logic, and file saving — everything you need for your Jarvis bot.
